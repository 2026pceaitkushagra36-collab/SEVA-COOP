# Seva-Coop Project Context

Welcome to the **Seva-Coop** project! This document provides context on the initial setup and structure of the repository.

## Project Structure
This is a Next.js application that includes integrations for **Supabase** and **AI tools**.

Key directories:
- `src/app/`: Next.js App Router pages and layouts.
- `src/components/`: Reusable React components.
- `src/lib/supabase/`: Supabase client configuration and database setup.
- `src/lib/ai/`: AI service integrations and logic.
- `src/services/`: Core application services.

## Next Steps
To get started with the project locally:
1. Clone the repository.
2. Run `npm install` to install all dependencies.
3. Copy `.env.example` to `.env.local` and add the necessary Supabase keys and API credentials.
4. Run `npm run dev` to start the development server.
