Fair work. Trusted services. Stronger communities.

SEVA-COOP is a community-run platform that connects people who need everyday home services, such as plumbing, electrical work, carpentry, and cleaning, with trusted local workers.

🔗 Live demo: https://seva-coop.vercel.app

## About the Project

Finding a reliable local worker is not always easy. Customers do not always know who to trust, and workers, especially in smaller towns, often struggle to find steady work.

SEVA-COOP is built like a cooperative rather than a typical booking app. A customer simply describes their problem, and the platform helps find a suitable nearby worker in a fair and transparent way.

## Who Uses It

- Customers: Ask for help easily and get a trusted worker.
- Workers: Receive jobs, build a work history, and track earnings.
- Cooperative admins: See local demand and where more skilled workers are needed.

## Key Features

- Describe a problem in your own words
- Fair matching of workers to jobs
- Safe, transparent job completion
- Simple dashboards for each type of user
- Insights that help the community plan better

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a local environment file:
   ```bash
   cp .env.example .env.local
   ```
4. Add your environment variables.
5. Start the development server:
   ```bash
   npm run dev
   ```

## Project Purpose

SEVA-COOP supports local service economies by making it easier for customers and workers to connect, while helping community organizations understand demand and workforce gaps.
